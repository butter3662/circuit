# 회로 만들기 시뮬레이터

격자 위에 부품을 끌어다 놓아 회로를 만들고, 전압·전류를 실시간으로 계산해 보여 주는 웹 시뮬레이터이다. 휴대폰과 PC에서 모두 동작하며, 설치 없이 `index.html` 한 파일로 실행된다.

## 기능

- 부품 18종: 도선, 전지, 교류 전원, 전류원, 저항, 전구, 스위치, 퓨즈, LED(5색), 다이오드, 축전기, 코일, 유도 코일(자속 변화율 일정 / 주기 운동, ε = −N dΦ/dt), 변압기, 전류계, 전압계, 접지, 층 연결
- 여러 층(최대 8층)으로 회로를 쌓고 층 연결로 잇기, 층별 2D 편집과 3D 회전 보기
- 교류 회로에서 계기의 실효값 표시
- 3D 보기에서도 부품 배치·이동·편집 가능
- Supabase 이메일 계정으로 로그인해 회로를 클라우드에 저장·불러오기 (표 정의는 `supabase.sql`, 본인 데이터만 접근하도록 행 수준 보안 적용)
- iPhone·iPad 홈 화면에 추가하면 앱처럼 실행(웹앱 아이콘 포함)
- 전류 흐름 애니메이션(관습 전류 / 전자 이동 방향 전환), 전위에 따른 도선 색 표시
- 선택한 부품의 전압·전류를 시간에 따라 그리는 그래프
- 단락, LED 과전류, 전구 과부하 경고
- 예제 회로: 직렬, 병렬, RC 충전·방전, LED, RL, 휘트스톤 브리지, 변압기, 반파 정류·평활, 전자기 유도, LC 전기 진동, 2층 회로
- 실행 취소, 브라우저 자동 저장, 두 손가락 확대·이동

## 계산 원리

- **노드 해석**: 각 노드에서 키르히호프 전류 법칙을 세워 연립방정식 **G v = i**를 만들고 부분 피벗팅 가우스 소거법으로 푼다. **G**는 컨덕턴스 행렬, **v**는 노드 전위 벡터, **i**는 전류원 항 벡터이다.
- **축전기·코일**: 후진 오일러법으로 이산화한다. 축전기는 I<sub>n</sub> = C(v<sub>n</sub> − v<sub>n−1</sub>)/Δt, 코일은 I<sub>n</sub> = I<sub>n−1</sub> + (Δt/L)v<sub>n</sub>이다.
- **변압기**: 결합 계수 k인 두 결합 코일로 v<sub>1</sub> = L<sub>1</sub>di<sub>1</sub>/dt + M di<sub>2</sub>/dt, v<sub>2</sub> = M di<sub>1</sub>/dt + L<sub>2</sub>di<sub>2</sub>/dt를 풀며, L<sub>2</sub> = (N<sub>2</sub>/N<sub>1</sub>)<sup>2</sup>L<sub>1</sub>, M = k√(L<sub>1</sub>L<sub>2</sub>)이다.
- **LED·다이오드**: 쇼클리 다이오드 방정식 I = I<sub>S</sub>(e<sup>V/(nV<sub>T</sub>)</sup> − 1)을 뉴턴–랩슨 반복으로 푼다.
- **계기**: 전류계는 내부 저항 1 mΩ, 전압계는 내부 저항이 무한대인 이상적 계기로 둔다.

각 식의 기호 정의와 자세한 설명은 사이트의 ☰ 메뉴 → 「사용법·계산 원리」에 있다.

## 한계

도선 저항은 0으로 보며, 전구 저항의 온도 의존성과 다이오드의 역방향 항복, 변압기 철심의 포화·손실은 모형에 없다. 후진 오일러법 특성상 LC 진동은 실제보다 빨리 감쇠한다.

## PC 조립 모드

위쪽의 **PC** 단추(또는 메뉴 → PC 조립 모드, 주소 끝에 `#pc`)로 들어간다.

- 정전기 방지 매트 위의 부품을 끌어 슬롯에 놓으면 체결된다. 부품 구성(2026년 11월 기준 최고 사양): Ryzen 9 9950X3D2 Dual Edition, GeForce RTX 5090, X870E 메인보드(Crosshair X870E Hero), DDR5-6000 32GB×2, WD_BLACK SN8100 4TB(PCIe 5.0), 1600W 80+ 티타늄 ATX 3.1 파워, NH-D15 G2 공랭 쿨러.
- CPU 소켓 레버, 램 래치, 확장 슬롯 덮개, 파워 스위치를 직접 조작하고, CPU 방향(금색 삼각형)과 램 노치 방향을 맞춰야 한다.
- 배선은 모두 직접 한다: 24핀, CPU 8핀(EPS) 2개, 그래픽카드 12V-2x6(16핀), 팬, 전면 패널(F_PANEL) 핀, USB 3.0, HD 오디오, 모니터, 전원 케이블.
- 전원 버튼을 누르면 디버그 LED(CPU·DRAM·VGA·BOOT)와 모니터 화면으로 부팅 결과를 보여 준다. 빠뜨린 부품·잘못 꽂은 케이블에 따라 실제와 비슷하게 실패한다.
- 왼쪽 위 **?** 단추는 다음에 할 일과 그 이유, 전체 진행 목록을 보여 준다.
- 진행상황은 브라우저에 자동 저장되고, 로그인하면 Supabase `pc_build_progress` 표에 계정별로 저장된다.
