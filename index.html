사용법과 계산 원리

사용법

  • 아래 도구 막대에서 부품을 고르고, 격자점을 눌러 다른 격자점까지 끌면 그 사이에 부품이 놓여요. 짧게 누르면 오른쪽으로 2칸 길이로 놓이고, 접지와 층 연결은 한 점만 누르면 돼요.
  • 끝점이 같은 격자점에 있는 부품끼리만 연결돼요. 도선 중간의 격자점에 다른 부품 끝이 닿으면 도선이 자동으로 나뉘어 연결되고, 두 도선이 끝점이 아닌 곳에서 교차하면 연결되지 않아요.
  • 선택 도구: 부품을 누르면 값 편집 창이 열려요. 부품을 끌면 옮겨지고, 선택된 부품의 끝점(a, b)을 끌면 길이와 방향이 바뀌어요. 스위치는 누를 때마다 열리고 닫혀요.
  • 변압기: 끌어 놓은 선이 1차 코일(a → b)이 되고, 그 옆 2칸 떨어진 곳에 2차 코일(c → d)이 생겨요.
  • 층: 왼쪽 위 층 단추로 편집할 층을 고르고, 더하기 단추로 층을 추가해요. 서로 다른 층의 같은 격자점은 연결되지 않고, 층 연결 부품을 놓아야 이어져요. 층 연결은 현재 층과 바로 위층(맨 위층이면 아래층)을 잇고, 편집 창에서 이을 층을 바꿀 수 있어요. 접지 기호는 층과 상관없이 모두 같은 노드예요.
  • 3D 단추: 모든 층을 쌓아서 입체로 봐요. 빈 곳을 한 손가락으로 끌면 회전하고(잡은 곳이 손을 따라 움직여요), 두 손가락이나 휠로 확대·이동해요. 3D에서도 2D처럼 부품을 놓고 옮기고 편집할 수 있고, 편집은 파랗게 표시된 현재 층 위에서 해요. 층은 왼쪽 위 단추로 바꿔요.
  • 계정·클라우드 저장: 메뉴에서 로그인하면 회로에 이름을 붙여 계정에 저장하고, 다른 기기에서 불러올 수 있어요. 카나미치·SEED 10K와 같은 계정이에요.
  • 단축키: Space 재생/정지, Ctrl+Z 실행 취소, Delete 삭제, R 회전, F 방향 뒤집기, Esc 선택 해제.
  • 회로는 이 브라우저에 자동 저장돼요.

1. 노드 해석

도선·닫힌 스위치·층 연결로 이어진 점들을 하나의 노드로 묶고, 각 노드에서 키르히호프 전류 법칙 ΣIout = 0을 세운다. Iout은 그 노드에서 각 소자로 빠져나가는 전류이다. 모든 소자의 전류를 노드 전위로 나타내면 연립일차방정식이 된다.

G v = i

G는 컨덕턴스 행렬(단위 S), v는 미지의 노드 전위 벡터(V), i는 각 노드로 들어가는 전류원 항의 벡터(A)이다. 접지가 있으면 접지 노드를, 없으면 전지의 −극 노드를 기준 전위 0 V로 둔다. 서로 떨어진 회로 덩어리마다 기준 노드를 하나씩 둔다. 부분 피벗팅 가우스 소거법으로 풀며, 행렬이 특이해지지 않도록 모든 노드와 기준점 사이에 Gmin = 10−12 S의 아주 작은 컨덕턴스를 둔다.

2. 소자 모형

아래에서 Va, Vb는 소자 양 끝 a, b의 전위, I는 소자 안에서 a → b로 흐르는 전류, Δt는 한 계산 단계의 시간 간격, 아래첨자 n은 시간 단계 번호이다.

  • 저항·전구: I = (Va − Vb) / R. R은 저항값(Ω)이다. 전구 밝기는 소비 전력 P = (Va − Vb)I를 정격 전력 P정격으로 나눈 비율이다. 필라멘트 저항의 온도 의존성은 무시한다.
  • 전지: 기전력 ε와 내부 저항 r의 직렬 연결이다(b가 +극).
    I = ( ε − (V+ − V−) ) / r
    I는 전지 내부에서 −극 → +극으로 흐르는 전류, V+ − V−는 단자 전압이다.
  • 교류 전원: 전지와 같은 모형에서 기전력만 시간에 따라 변한다.
    ε(t) = Vp sin(2πft)
    Vp는 진폭(최댓값), f는 주파수(Hz), t는 시뮬레이션 시각(s)이다. 실효값은 Vp/√2이다.
  • 유도 코일: 감은 수 N인 코일을 지나는 자속 Φ가 변하면 패러데이 법칙에 따라 기전력이 생긴다.
    ε = −N dΦ/dt
    ε는 코일 안 a → b 방향을 양으로 잡은 유도 기전력, Φ는 한 바퀴를 지나는 자속(Wb)이며, Φ의 양의 방향은 a → b로 감긴 코일에 오른손 법칙을 적용해 정한다(음의 부호는 렌츠 법칙). 두 가지 운동을 고를 수 있다.
    일정 변화: Φ(t) = kt → ε = −Nk    주기 운동: Φ(t) = Φmax cos(2πft) → ε = 2πf N Φmax sin(2πft)
    k는 일정한 자속 변화율 dΦ/dt(Wb/s), Φmax는 최대 자속, f는 자석이 왕복하는(또는 코일이 회전하는) 진동수이다. 코일 자체의 저항 r와 자체 유도 계수 L을 넣으면 단자 사이의 관계는 다음과 같고, 후진 오일러법으로 이산화한다.
    Vb − Va = ε − rI − L dI/dt
    I는 코일 안에서 a → b로 흐르는 유도 전류이다. 유도 전류가 만드는 자속이 다시 Φ에 더해지는 효과는 L에 포함된다.
  • 전류원: 양단 전압과 관계없이 소자 안에서 a → b로 일정한 전류 I를 흘린다. 열린 회로에 연결하면 전압이 한없이 커지므로 경고가 뜬다.
  • 축전기: i = C dv/dt를 후진 오일러법으로 이산화한다.
    In = C ( vn − vn−1 ) / Δt
    C는 전기 용량(F), v = Va − Vb는 양단 전압이다.
  • 코일: v = L di/dt를 같은 방법으로 이산화한다.
    In = In−1 + (Δt / L) vn
    L은 자체 유도 계수(H)이다.
  • 변압기: 상호 유도로 결합된 두 코일로 모형화한다. 1차 코일 양 끝이 a, b, 2차 코일 양 끝이 c, d이며, 점(•)이 찍힌 a와 c가 같은 극성의 끝이다.
    v1 = L1 di1/dt + M di2/dt,   v2 = M di1/dt + L2 di2/dt
    L2 = (N2/N1)2 L1,   M = k √(L1L2)
    v1 = Va − Vb, v2 = Vc − Vd는 1·2차 전압, i1, i2는 각 코일 안에서 a → b, c → d로 흐르는 전류, L1, L2는 자체 유도 계수, M은 상호 유도 계수, N1, N2는 감은 수, k(0 < k < 1)는 결합 계수이다. 후진 오일러법으로 이산화하면
    [i1, i2]n = [i1, i2]n−1 + Δt L−1 [v1, v2]n,   L = [[L1, M], [M, L2]]
    이 된다. k → 1이고 코일의 리액턴스 2πfL1이 부하에 비해 충분히 크면 v2/v1 ≈ N2/N1인 이상 변압기에 가까워진다. 철심의 자기 포화와 손실은 모형에 없다.
  • LED·다이오드: 쇼클리 다이오드 방정식을 쓴다. a가 애노드, b가 캐소드이다.
    I = IS ( eV / (n VT) − 1 ),   VT = kT / q
    V = Va − Vb, IS는 포화 전류, n은 이상 계수(2로 둠), VT는 열전압, k는 볼츠만 상수, T는 절대 온도(300 K로 둠), q는 기본 전하량이며 VT ≈ 25.85 mV이다. IS는 20 mA에서의 순방향 전압이 다이오드 0.7 V, LED 빨강 1.8 V, 노랑 2.0 V, 초록 2.2 V, 파랑·흰색 3.0 V가 되도록 정했다. 뉴턴–랩슨 반복으로 풀고, 반복마다 다이오드 전압 변화량을 제한해 발산을 막는다. 역방향 항복은 모형에 없다.
  • 퓨즈: 저항 10 mΩ의 도체이며, 전류의 크기가 정격 전류를 넘는 순간 끊어져(열린 회로) 다시 연결되지 않는다. 편집 창의 교체 단추나 초기화로 복구한다.
  • 도선·닫힌 스위치·층 연결: 저항 0으로 보고 양 끝을 같은 노드로 합친다. 접지: 모든 접지 기호를 하나의 노드로 합쳐 0 V로 둔다.
  • 전류계: 내부 저항 1 mΩ. 전압계: 내부 저항이 무한대인 이상적 계기. 둘 다 a가 +단자이다.

3. 시간 진행과 실효값

화면을 한 번 그릴 때마다(약 1/60 s) 실제로 흐른 시간에 속도 배율을 곱한 만큼 시뮬레이션을 진행한다. 이를 여러 단계로 나누어 계산하는데, 한 단계의 Δt는 직류만 있으면 1/240 s 이하, 교류 전원이 있으면 1/(50fmin) 이하로 한다(fmin은 가장 낮은 교류 주파수). 축전기와 코일이 함께 있으면 Δt ≤ 0.003√(LminCmin)로 더 줄인다(Lmin, Cmin은 회로에서 가장 작은 자체 유도 계수와 전기 용량). LC 진동의 각진동수 ω = 1/√(LC)에 대해 ωΔt ≤ 0.003이 되어, 후진 오일러법 때문에 생기는 인위적 감쇠가 한 주기에 약 1%(≈ πωΔt)로 작아진다. 한 프레임에 600단계를 넘으면 경고를 띄운다. 후진 오일러법은 Δt가 커도 수치적으로 안정하다.

계기의 실효값은 순간값의 제곱을 지수 이동 평균한 뒤 제곱근을 취해 구한다.

Xrms = √⟨x2⟩,   ⟨x2⟩n = ⟨x2⟩n−1 + (Δt/τ)( xn2 − ⟨x2⟩n−1 )

x는 전압 또는 전류의 순간값, ⟨x2⟩는 그 제곱의 평균, τ는 평균 시간 상수로 교류가 있으면 2/fmin, 없으면 0.3 s이다. 그래서 회로를 바꾼 직후 몇 주기 동안은 실효값이 정착되는 중이다. 계기는 회로에 교류 전원이 있으면 자동으로 실효값(값 뒤에 ~ 표시)을 보여 주며, 편집 창에서 순간값으로 바꿀 수 있다.

4. 도선의 전류 분배

도선은 저항이 0이므로, 도선끼리 고리를 이루면 각 도선의 전류가 노드 해석만으로는 정해지지 않는다. 흐름 점 애니메이션을 위해 도선마다 길이에 비례하는 아주 작은 저항이 있다고 가정해 분배를 계산한다. 부품의 전압·전류와 계기 값에는 영향이 없다.

5. 3D 보기

층 z(0부터 셈)의 격자점 (x, y)를 3차원 점 (x, y, hz)로 두고(h는 층 간격), 수직축 둘레로 각 θ만큼 돌린 뒤 수평축 둘레로 각 φ만큼 기울여 화면에 정사영한다. 정사영에서 평면은 평면으로 선형 사상되므로, 각 층은 2D 화면과 같은 그림을 아핀 변환해 그린다.

6. 경고 기준

전지·교류 전원 전류가 5 A 초과(단락 의심), LED 전류 30 mA 초과, 전구 전력이 정격의 1.5배 초과, 노드 전압 10 kV 초과일 때 경고한다. 학교 실험용 부품을 생각해 정한 값이다.
